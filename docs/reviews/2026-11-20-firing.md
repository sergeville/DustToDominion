# Firing input correction — 2026-11-20

## 1. Finding and change

Serge reported that fire did not work. A reproducible input bug exists outside
the station shield: if left-button down/up both arrive before a fixed update,
the released state overwrites the press and no projectile is created. Two
regressions failed against the preceding code, in one batch and across batches.

The screen now retains one click/aim until the next consumed simulation step.
Held fire continues using current aim. A blocked click is consumed, so cooldown
and shield restrictions cannot queue a surprise later shot. Pause, focus loss,
launch and mode transitions clear pending input.

The station shield intentionally prevents firing. English/German HUD text now
explicitly tells the player to leave the shield. Space mines; left click fires.
The model, weapon balance, save schema and dependency pins are unchanged.

load the corrected input handler. Then fly beyond the outer station circle and
left-click or hold left click. To mine a nearby rock, hold Space.
