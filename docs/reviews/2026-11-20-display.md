# Display validation — 2026-11-20

Serge requested a larger default window, confirmed proportional text scaling,
and specified that fullscreen must use the screen's resolution.

- Windowed: 1920x1080; fallback 1280x720 when the desktop lacks 64px of
  extra width/height, or desktop dimensions are unavailable.
- Fullscreen: native desktop mode via SDL, with a 1920x1080 logical canvas
  scaled proportionally and letterboxed. Font selection/sizes are unchanged.
- F11 or macOS Ctrl+Cmd+F toggles. Old resolution settings remain readable,
  but no longer select a physical monitor mode.
- No new dependencies and no campaign/save format changes.

## Validation

Full suite: **1,781 passed in 36.20s**, with one expected dummy-renderer warning.
Focused window/config/main suite: **125 passed**.

[Native probe](check_native_display.py) ran on the actual macOS display backend
with isolated temporary settings and a synthetic station. It observed:

| Phase | Physical window | Logical surface |
| --- | --- | --- |
| Initial window | 1920x1080 | 1920x1080 |
| Fullscreen, twice | 3440x1440 | 1920x1080 |
| Returned window, twice | 1920x1080 | 1920x1080 |

Both desktops remained 3440x1440 and 1710x1107 throughout. SDL mouse positioning
round-tripped in logical coordinates; injected mouse-button events activated
View fleet in both fullscreen cycles. This is a native renderer/API smoke test,
not a human gameplay or physical mouse-click acceptance test.

- [Raw native measurements](2026-11-20-display/native-display.json)
- [1920x1080 station capture](2026-11-20-display/windowed.png), visually inspected
  for text clipping and layout; this captures the logical surface, not black bars.
- Underlying behavior checked against the pinned
  [pygame-ce 2.5.8 display implementation](https://github.com/pygame-community/pygame-ce/blob/2.5.8/src_c/display.c):
  SCALED fullscreen selects SDL_WINDOW_FULLSCREEN_DESKTOP.

Run from the project root:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python docs/reviews/check_native_display.py
```

The native probe assumes Serge's main desktop fits 1920x1080 and tests the
macOS shortcut. Windows/Linux native behavior and moving the window between
monitors were not tested. The inherited monitor lookup assumes a horizontal
arrangement; this change does not claim to repair arbitrary multi-monitor
routing. Native main-monitor rendering/toggling is verified; gameplay balance,
audio and full campaign play acceptance remain separate.
